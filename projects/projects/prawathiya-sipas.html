Executive Overview & Background

A prominent IT outsourcing firm in Jakarta struggled with a rigid legacy software that failed to accommodate complex client-specific HR policies, employee status mutations, and custom payroll structures. As a result, critical operational gaps—such as salary setup, allowance breakdowns, and contract renewals—were handled manually in Excel spreadsheets and re-uploaded into legacy software, creating high risk of human error and legal exposure.

Key Business Objectives

  • End-to-End Lifecycle Digitization: Track complete employee lifecycles from recruitment application, processing, rejection/acceptance, contract extension, to resignation.
  • Multi-Status Employment Governance: Support dynamic employment schemes, including PKWT (contract), PKWTT (permanent), casual daily workers, and core employees.
  • Dynamic Multi-Company Rule Setup: Enable configurable client company profiles with customized salary structures, allowances, job grades, and regulatory compliance.
  • Automated Legal Document Engine: Auto-generate official PDF Employment Contracts (detailing base salary & allowances) and Paklaring certificates required for BPJS Employment claims.
  • Seamless Internal API Integration: Bridge payroll data securely via REST API with an existing internal application managed by a separate engineering division.

Process Re-Engineering (As-Is vs To-Be)

As-Is Workflow (Legacy)

Rigid legacy system unable to handle custom client rules. Employee mutations, salary grade calculations, and contract extensions required cumbersome manual Excel workarounds and manual PDF contract drafting.

To-Be Workflow (SIPAS System)

Centralized web platform with configurable multi-company rule engines, automated PDF contract & Paklaring generation, full audit trails, and automated REST API payload exchange for payroll processing.

System Solution & Scope

Multi-Company Configuration Portal

Allows admins to setup dynamic company profiles, distinct salary grades, allowance rules, and regulatory setups for every client company joining the ecosystem.

Flexible Employment Matrix

Manages multi-tier employee categories (PKWT, PKWTT, Daily, Permanent) with dedicated mutation tracking across different client placements.

Dynamic PDF Document Engine

Automatically populates employee variables into legally binding PDF Employment Contracts and post-resignation Paklaring certificates for BPJS claims.

Payroll & API Integration Module

Calculates base pay, allowances, and deductions while exposing secure REST API endpoints to exchange payroll payloads with internal legacy platforms.
